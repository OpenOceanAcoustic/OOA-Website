# 前端视觉整改记录

依据 [前端视觉审计](前端视觉审计.md)，保留深海背景与青色强调，完成以下调整。

| 审计问题 | 整改结果 |
| --- | --- |
| Ray 整页溢出 | 移除首屏与本征声线区的固定网格最小宽度；长公式和到达表格仅在容器内滚动 |
| 标题与必要文字比例失衡 | 主标题响应式 30–48px；参数标签、输入和按钮 14px；必要说明 13–15px；图表刻度 12px |
| 首屏过长 | 增加原理、实验台、结果入口；精简运行信息；原理图先于长公式；Ray 推导可展开 |
| 参数栏拥挤 | 三种模型参数栏均可折叠；Normal/PE 的物理参数分组可独立折叠；隐藏操作区接口标签 |
| Ray 主图过窄、浮层遮挡 | 中等宽度改为上下主图，宽屏并列；状态与操作提示移出数据绘图区；工具条自适应换行 |
| Normal 选中模态不明显 | 添加中文点击提示；选中节点增大并加描边；保留阶数、水平波数和单位读数 |
| PE 标题断词 | 改为“Padé 阶数如何影响声场” |
| PE 对照结果相隔过远 | 同一结果区切换 TL/ΔTL 或双图对照；同一距离选择同时更新两图和垂向剖面；中等视口默认单张大图 |
| PE 色标与声速刻度 | 色标提供 220px 空间、五个刻度和 dB 单位；ΔTL 以零为中心；声速轴显示实际 m/s 数字 |
| 海底区域语义不明确 | 保留海底计算域，并在足够空间内直接标注“海底介质” |

## 验证

- 类型检查、导入边界、页面结构、85 项单元测试及 12 项构建脚本测试通过（原有 1 项单元测试跳过）。
- 浏览器回归覆盖真实 WASM 运算、环境文件导入、浅水声源、图表交互、页面导航及本次视觉验收；首轮发现的工具条遮挡已修复，相关回归通过。
- 1280、1440、1920、390、640 CSS px 宽度下，无整页横向溢出；参数栏展开/收起均检查。640 CSS px 验证 1280px 显示在 200% 缩放时的等效布局宽度，不代表已验证所有浏览器的原生缩放实现。
- Ray 展开公式后另检查了 1280px 与 390px 页面宽度。
- 完整发布入口原有的 WASM 来源一致性校验问题仍存在；本次前端打包和浏览器验证使用现有本地 WASM 包。
