# OpenOcean Bellhop 交互实验室

一个零第三方依赖的 OOB/Bellhop 教学网页：左侧设置声速环境，中间动态展示声线，右侧联动显示传播损失预览。SSP 在 0–5000 m 范围内每 500 m 提供一个可水平拖动的声速节点；海底半空间的纵波声速、密度和吸收也可实时调节。进阶实验通过反射拓扑分组与二分求根计算本征声线；接收器可直接在 0–100 km 距离—深度图上拖动，松开后自动重新求解，并展示接收点收敛、到达时延、幅度、相位和相干传播损失。

```bash
python3 server.py
```

浏览器打开 <http://127.0.0.1:8000>。

网页中的快速射线追踪和传播损失场用于交互教学。工程结果应使用同目录 `OpenOcean-Field-RayMode` 中的原生 Bellhop2D 求解器生成。
